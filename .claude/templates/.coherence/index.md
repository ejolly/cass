# Project coherence

This site records accepted knowledge that keeps the project conceptually consistent across changes and agent sessions. The Markdown files in `.coherence/` are the source of truth; this site is a rendered view of them.

| Record | Purpose | How to use it |
| --- | --- | --- |
| [Domain](domain.md) | Shared terminology and conceptual distinctions | Read before substantive work |
| [Commitments](commitments.md) | Binding project agreements | Read before substantive work |
| [Decisions](decisions.md) | Rationale for consequential choices | Consult the index and relevant records selectively |

A decision explains *why* something was chosen, but is not itself a binding rule. Only a commitment establishes what may not change without deliberate human approval.

These records contain accepted knowledge only. Proposed rules, unresolved ambiguities, and review findings belong in discussion until the human approves their incorporation.
